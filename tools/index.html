ADB 工具

        
通过本机 ADB 桥管理多台设备：文件、安装、应用、网络代理/转发、开发者选项、Logcat、输入与截图录屏。使用前需本机已安装 adb，并启动本地桥接服务。不会装？看小白指南

      

      

        

          

            
            

              未连接本机桥
              
请下载完整 ZIP（含 server.js 与启动脚本），解压后运行脚本，再点「连接本机桥」。

            

          

          

            
            
            
              
              
              
            
          

        


        

          
          
          
          
        

        
默认 Token 为 devtools-adb。桥仅监听本机。文件默认从 / 浏览（类似 Android Studio Device File Explorer）；无权限时会尝试 su / run-as，/data/data 无 root 时按包名虚拟列出。完整包需含 server.js（桥 ≥0.6.12），请解压到同一文件夹后运行启动脚本。

        

          本机依赖怎么配？

网络（抓包 / 端口）

                当前设备全局代理
              

              

                这是干什么的？
                把手机的 HTTP/HTTPS 流量转到电脑上的 Charles、mitmproxy、Fiddler 等工具，方便看接口。端口转发则是让电脑和手机上的本地服务互相「打通」，不必改应用里的 IP。
                
    
                  
  1. 电脑与手机连同一 Wi‑Fi；电脑打开抓包软件，记下监听端口（常见 8888 / 8080）。
    2. 
                  
  2. Host 填电脑的局域网 IP（本页若用局域网地址打开会尝试预填）；Port 填抓包端口。
    3. 
                  
  3. 点「设置代理」。手机浏览器访问一次抓包工具的证书页并安装证书（HTTPS 才看得见内容）。
    4. 
                  
  4. 抓完务必点「清除代理」，否则手机会一直走电脑，断网或打不开网页。
    5. 
                

                
端口转发怎么选？

                
    
                  
  • forward（电脑→手机）：本机访问 localhost:本地端口 实际连到手机上的服务（例如调试手机里起的 HTTP）。
    • 
                  
  • reverse（手机→电脑）：手机访问 localhost:远端端口 实际连到电脑上的服务（常见：手机 App 调你电脑上的后端）。

5. 常见问题

          

            
提示找不到 node / ffmpeg / adb

            
确认已安装；Windows 改完 PATH 后必须新开终端；用上面的 -v / -version 命令自测。

            
桥连不上

            
确认启动窗口还在跑；地址端口别填错；浏览器要用 https 本站或本机预览，不要用 file:// 直接打开 HTML。

            
手机 adb devices 是空的

            
检查线材、USB 调试、手机上的授权弹窗；换口 / 换线；部分机型要开「仅充电」以外的文件传输模式。

            
手机上怎么用 FFmpeg？

            
手机装不了本机桥。请用媒体里的 音频处理 / 视频修剪（网页内 FFmpeg）。电脑批量再用本机桥。

            
只想批量抽音频，要不要装 ADB？

            
不用。装 Node.js + FFmpeg，用 FFmpeg 本机桥 即可。

            
偶尔处理一两个视频，要不要装本机桥？

            
不必。用媒体里的「音频处理 / 视频修剪」等浏览器内工具就够（也是保底方案）；几百个文件再上本机桥。
