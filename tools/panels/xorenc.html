XOR 半段加解密

对 UTF-8 文本或任意二进制文件做「前半 XOR + 全量 XOR」可逆混淆；两个密钥默认 4 与 7，可自定义（0–255）。

加解密须使用相同两个数；任意 0–255 均可，不限于 4 和 7。

文本

文件

对原始字节流加解密，不经过 UTF-8 文本转换；加密后下载为 *.xorenc。

算法说明与主流语言写法

原理（可自定义两个密钥）

设明文为字节数组 P，长度为 n，前半长度为 ⌊n/2⌋，两个密钥为 a、b（默认 a=4，b=7，取值 0–255 任意）：

  1. 加密：先对 P[0 … ⌊n/2⌋−1] 逐字节 XOR a；再对 P[0 … n−1] 全部 XOR b。
  2. 解密：顺序相反——先全体 XOR b，再前半 XOR a（XOR 自身可逆，故可还原）。

文本模式：字符串 ↔ UTF-8 字节 ↔ 上述运算 ↔ 再解码为字符串（非法 UTF-8 序列会被替换，与 Kotlin/JVM 行为一致）。文件模式：直接对文件原始字节运算。

能否改 4 和 7？ 可以。只要加解密使用同一对 (a, b) 即可；数值越大并不更安全，这仍是简单混淆而非密码学加密。

Kotlin（原版）

fun xorEncrypt(data: ByteArray, a: Int, b: Int): ByteArray {
    val n = data.size
    val half = n / 2
    for (v in 0 until half) data[v] = (data[v].toInt() xor a).toByte()
    for (v in 0 until n) data[v] = (data[v].toInt() xor b).toByte()
    return data
}
fun xorDecrypt(data: ByteArray, a: Int, b: Int): ByteArray {
    val n = data.size
    val half = n / 2
    for (v in 0 until n) data[v] = (data[v].toInt() xor b).toByte()
    for (v in 0 until half) data[v] = (data[v].toInt() xor a).toByte()
    return data
}

JavaScript / TypeScript

function xorCrypt(bytes, keyHalf, keyAll, decrypt = false) {
  const arr = new Uint8Array(bytes);
  const n = arr.length, half = Math.floor(n / 2);
  if (!decrypt) {
    for (let i = 0; i < half; i++) arr[i] ^= keyHalf;
    for (let i = 0; i < n; i++) arr[i] ^= keyAll;
  } else {
    for (let i = 0; i < n; i++) arr[i] ^= keyAll;
    for (let i = 0; i < half; i++) arr[i] ^= keyHalf;
  }
  return arr;
}

Python

def xor_crypt(data: bytearray, a: int, b: int, decrypt: bool = False) -> bytes:
    n = len(data)
    half = n // 2
    if not decrypt:
        for i in range(half): data[i] ^= a
        for i in range(n): data[i] ^= b
    else:
        for i in range(n): data[i] ^= b
        for i in range(half): data[i] ^= a
    return bytes(data)

    return data;
}

func xorCrypt(data []byte, a, b byte, decrypt bool) {
    n, half := len(data), len(data)/2
    if !decrypt {
        for i := 0; i < half; i++ { data[i] ^= a }
        for i := 0; i < n; i++ { data[i] ^= b }

        for i := 0; i < n; i++ { data[i] ^= b }

    }
}
