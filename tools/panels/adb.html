默认 Token 为 devtools-bridge（兼容旧 devtools-adb）。一座桥同时提供 ADB、Scrcpy 镜像与 FFmpeg（/ff）。完整包需含 server.js + ffmpeg-bridge/（桥 ≥0.8.0）。

本机依赖怎么配？
  1. ADB（必装）：安装 Android SDK platform-tools，终端能跑 adb devices。macOS：brew install android-platform-tools；Windows：从 Google 下载 Platform-Tools 并把目录加入 PATH；Linux：发行版包或官网 zip。
  2. 本机桥：下载上方完整 ZIP → 解压（同目录保留 server.js）→ 运行启动脚本 → 点「连接本机桥」。桥已启动但提示找不到 adb 时，先修好 PATH 再重启桥。
  3. APK 签名分析（可选）：装 JDK（提供 keytool），或装 Android build-tools（提供 apksigner）并加入 PATH；也可装 openssl 作证书回退。

连接桥后会显示本机工具探测结果。

APK 安装

可安装到当前设备或勾选的多台设备

普通/调试包：勾选覆盖；装更低版本再勾「允许降级」。签名不一致通常要先卸载。分析会尽量给出别名/CN/SHA1/SHA256（需本机 keytool 或 apksigner）。系统预装应用：分析后填包名，点「推送到系统路径」会按包名查找现有 APK 路径并同名覆盖。

签名工具未就绪？
  • 安装 JDK 17+，确认终端里 keytool -help 可用；若只用 GUI 启动桥，请重启桥（新版启动脚本会自动补 JAVA_HOME / Homebrew OpenJDK 路径）。
  • 解析仅有 v2/v3 的 APK 需要 apksigner：安装 Android SDK build-tools 并加入 PATH（仅有 keytool 不够）。
  • 可选：安装 openssl，用于解析 META-INF 证书。
  • 配好后重启本机 ADB 桥（完整 ZIP 包需 ≥0.6.10）再点「分析 APK 信息」。失败时看分析结果里的「工具路径 / 错误」行，对照连接区 keytool✓/✗、apksigner✓/✗。

网络（抓包 / 端口）

                当前设备全局代理
              

              

                这是干什么的？
                把手机的 HTTP/HTTPS 流量转到电脑上的 Charles、mitmproxy、Fiddler 等工具，方便看接口。端口转发则是让电脑和手机上的本地服务互相「打通」，不必改应用里的 IP。
                
    
                  
  1. 电脑与手机连同一 Wi‑Fi；电脑打开抓包软件，记下监听端口（常见 8888 / 8080）。
    2. 
                  
  2. Host 填电脑的局域网 IP（本页若用局域网地址打开会尝试预填）；Port 填抓包端口。
    3. 
                  
  3. 点「设置代理」。手机浏览器访问一次抓包工具的证书页并安装证书（HTTPS 才看得见内容）。
    4. 
                  
  4. 抓完务必点「清除代理」，否则手机会一直走电脑，断网或打不开网页。
    5. 
                

                
端口转发怎么选？

                
    
                  
  • forward（电脑→手机）：本机访问 localhost:本地端口 实际连到手机上的服务（例如调试手机里起的 HTTP）。
    • 
                  
  • reverse（手机→电脑）：手机访问 localhost:远端端口 实际连到电脑上的服务（常见：手机 App 调你电脑上的后端）。

Logcat

                拉取当前设备最近日志
              

              

                怎么填过滤？
                
    
                  
  • Tag：日志标签，对应代码里的 Log.d("MyTag", …)，只填标签名，如 ActivityManager、OkHttp。
    • 
                  
  • 包名：只看某个 App，填完整包名如 com.example.app（桥会尽量按进程过滤）。
    • 
                  
  • 关键字：对已拉取的文本再做包含匹配，可填错误码、URL 片段、Exception 名。
    • 
                  
  • 可组合使用；勾选「实时刷新」每 2 秒按当前条件重拉。先缩小 Tag/包名再开实时，避免刷屏。
