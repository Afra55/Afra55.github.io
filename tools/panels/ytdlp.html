yt-dlp 本机桥

用本机已安装的 yt-dlp 解析并下载视频 / 播放列表 / 字幕 / 直播。走同一座本机桥（/ytdlp），文件只落在你电脑上。不会装？看安装教程

未连接本机桥

请先下载完整 ZIP 并运行启动脚本，本机 PATH 中需有 yt-dlp；合并/抽音还需要 ffmpeg。

与 ADB / FFmpeg 共用一座本机桥：地址 17888、Token devtools-bridge。yt-dlp 接口在 /ytdlp/*；完整包需含 server.js + ytdlp-core.js。

本机依赖怎么配？
  1. Node.js（必装）：用来跑本机桥小服务。终端能跑 node -v。详见 安装指南 · Node.js。
  2. yt-dlp（必装）：终端能跑 yt-dlp --version。macOS：brew install yt-dlp；Windows：winget install yt-dlp 或 pipx；Linux：pipx install yt-dlp 或发行版包。详见下方教程或 全局安装说明。
  3. FFmpeg（强烈建议）：合并音视频、只下音频转 mp3 时需要。终端能跑 ffmpeg -version。详见 安装指南 · FFmpeg。
  4. 本机桥：下载上方完整 ZIP → 解压（同目录保留 server.js 与 ytdlp-core.js）→ 运行启动脚本 → 点「连接本机桥」。桥已连上但提示找不到 yt-dlp 时，先修好 PATH 再重启桥。
  5. 会员 / 高码率（可选）：在下方选项里选「cookies 浏览器」，让 yt-dlp 读取你浏览器已登录的 Cookie；或导出 cookies.txt 填路径。

连接桥后会显示本机 yt-dlp / ffmpeg 探测结果。

          yt-dlp 安装教程：从零到能下载
          

            
1. 它是什么？为什么要本机桥？

            
yt-dlp 是开源命令行工具，能解析 YouTube、B 站等上千个站点并下载视频、音频、字幕与元数据。浏览器网页不能直接代你下载（跨域与版权限制），所以本站通过本机桥调用你电脑上已安装的 yt-dlp——链接与文件都只在你本机处理，不上传服务器。


            
2. 你需要准备什么

            
    
              
  • 电脑（Windows / macOS / Linux）。手机浏览器无法跑本机桥，请用电脑。
    • 
              
  • Node.js：跑桥服务。安装步骤
    • 
              
  • yt-dlp：真正干活的下载器（本节重点）。
    • 
              
  • FFmpeg（建议）：合并分离的音视频、转 mp3 等。安装步骤
    • 
              
  • 本页完整 ZIP 桥：点上方「下载 xxx 完整包」，解压后运行启动脚本。
    •

  4. 改完 PATH 后必须重新打开命令行窗口再验证。

4. 启动本机桥并连接

            
    
              
  1. 在本页点「下载 macOS / Windows / Linux 完整包」→ 解压到同一文件夹（含 server.js、ytdlp-core.js、启动脚本）。
    2. 
              
  2. 运行启动脚本，保持窗口不要关（Windows 用 .cmd 更稳）。
    3. 
              
  3. 回到本页，确认桥地址 http://127.0.0.1:17888、Token devtools-bridge，点「连接本机桥」。
    4. 
              
  4. 状态变绿且出现工作区后，粘贴链接 → 选保存目录 → 开始下载。
    5. 
            

            
若 ADB 或 FFmpeg 桥已在跑，不必再起第二个——同一端口即可，只要 ZIP 里含 ytdlp-core.js（桥 ≥ 对应版本）。


            
5. 常见问题

            

              
桥连上了，但提示「未找到 yt-dlp」

              
终端自测 yt-dlp --version；Windows 改 PATH 后新开终端；装好后重启桥。也可设环境变量 YTDLP_PATH 指向可执行文件。

              
能解析但合并失败 / 只有视频没声音

              
安装 FFmpeg 并确认 ffmpeg -version 可用；选「最佳（视频+音频合并）」模式。

              
会员专享 / 年龄限制 / 403

              
在「Cookies / 代理」里选已登录的浏览器（chrome / edge 等），或提供 cookies.txt。

              
手机能用吗？

              
不能。本工具依赖电脑上的 yt-dlp 与桥服务；手机请用各平台官方 App 或其它方式。
