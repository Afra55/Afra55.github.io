Git 可视化

本机调用系统 git：默认挂在统一桥（与 ADB/FFmpeg 同座）。选仓库、看分支交叉、新手三步提交，并显示将要执行的命令。安装指南 · 下载完整包

未连接本机桥

与 ADB / FFmpeg 共用一座桥。下载统一完整包并启动后点「连接」。默认端口 17888。

零难度就绪（约 2 分钟）

  1. 去 环境管家 一键安装 Node / Git，并同步桥文件。
  2. 或在本页下载统一完整包，解压后运行启动脚本一次。
  3. 回到本页点「一键启动并连接」。
打开环境管家 下载统一完整包

账号登录请在本机 Git / 系统凭据里自行完成；本页只管点按钮操作仓库。

协议 devtools-bridge://。下载的是与 ADB 相同的统一完整包（含 Git），不要再用独立 Git 包。

默认走统一桥 17888 · API /git/* · Token devtools-bridge。完整包启动一次即可覆盖 ADB / FFmpeg / yt-dlp / Git。

选择仓库

拖文件夹进来，或点带「仓库」标记的目录，或粘贴路径

浏览器通常给不出本机绝对路径。请粘贴文件夹路径，或从下方目录列表点选；拖拽在部分浏览器可用。

把文件夹拖到这里

从资源管理器 / Finder 拖入仓库文件夹；拿不到路径时请粘贴到上方输入框。

两边改冲突了

每个冲突文件三选一：留我的、留对方的，或打开编辑自己改。改完点「保存并标记已解决」。全部解决后点「继续合并」。

绿块是一边、蓝块是另一边。可点「下一处冲突」跳转；删掉标记只留你要的内容再保存。
