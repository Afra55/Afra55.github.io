Git 可视化

本机桥调用系统 git：选仓库、看分支交叉、用人话解释 merge；白名单命令覆盖查阅 / 提交 / 分支 / stash / 合并 / 远程。安装指南

未连接 Git 桥

下载完整包并启动后点「连接」。默认端口 17890。

下载解压后把文件夹路径填在这里并「记住」。首次请手动双击启动脚本（会注册 devtools-git://）。之后网页可自动唤起：若已手动打开窗口，浏览器再弹出请点取消。

独立桥端口 17890（与 ADB 17888 / FFmpeg 17889 分开）。Token 默认 devtools-git，也接受 devtools-bridge。

选择仓库

拖文件夹进来，或点带「仓库」标记的目录，或粘贴路径
把文件夹拖到这里

从资源管理器 / Finder 拖入仓库文件夹；拿不到路径时请粘贴到上方输入框。

当前仓库

新手三步（不用记命令）

  1. 看下面「改了哪些文件」，勾选要保存的。
  2. 写一句人话说明，点「提交」。
  3. 需要同步到 GitHub 等远程时，再点「推送」。

打开仓库后显示未提交变更。

提交 = 把勾选的改动记进历史；推送 = 上传到远程（需已配置 remote）。
