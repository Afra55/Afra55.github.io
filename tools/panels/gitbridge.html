Git 可视化

本机调用系统 git：默认挂在统一桥（与 ADB/FFmpeg 同座）。选仓库、看分支交叉、新手三步提交，并显示将要执行的命令。安装指南 · 下载完整包

未连接本机桥

与 ADB / FFmpeg 共用一座桥。下载完整包并启动后点「连接」。默认端口 17888。

推荐到 ADB 下载完整包（已含 git-bridge），只需启动一次。协议 devtools-bridge://。下方「独立包」仅给只想用 Git、不装 ADB 的场景。

默认走统一桥 17888 · API /git/* · Token devtools-bridge。若仍用旧独立 Git 桥，地址改 17890、Token devtools-git。

小白模式（不用记命令）

打开仓库后，这里会用人话告诉你「现在可以做什么」。

日常同步

Gerrit / 已提交未合入想重来：先确认不需要本地多出来的提交，再点「对齐到网上最新」。

保存与改说明

  1. 勾选要保存的文件（默认全勾）。
  2. 写一句人话说明，点「保存到历史」。
  3. 需要同步到远程时，再点「② 上传我的改动」。

打开仓库后显示未提交变更。

「保存到历史」= 记一笔本地记录；「改上一笔」= 还没上传时改最近一笔；「上传」= 发到远程。

工作线

临时收起 · 撤销 · 合并提交

笔合成一笔

打补丁 · 恢复补丁

笔 → 补丁文件

补丁默认写到仓库内 .devtools-patches/。Gerrit 导出的 .patch 也可填路径后恢复。

两边改冲突了

每个冲突文件三选一：留我的、留对方的，或打开编辑自己改。改完点「保存并标记已解决」。全部解决后点「继续合并」。

文件里若有 <<<<<<< / ======= / >>>>>>> 标记：中间线以上是一边，以下是另一边。删掉标记，只留你要的内容，再点保存。
