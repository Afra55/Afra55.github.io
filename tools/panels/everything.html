无法从当前页面直连本机

HTTPS 站点访问 http://127.0.0.1 可能被浏览器拦截。可改用「Everything 网页」，或把本站保存到本机 / localhost 打开后再搜。

未连接 Everything

请在本机 Windows 安装 Everything 并启用 HTTP Server，再点「测试连接」。

默认端口 80；改过端口请写 http://127.0.0.1:8080。HTTP 用户名/密码在此填写。

怎么启用 HTTP Server？
  1. 安装 Everything：从 voidtools 官网 下载 Windows 版；首次运行建立索引。
  2. 启用 HTTP：Everything → 工具 → 选项 → HTTP Server → 勾选 Enable HTTP server → 允许文件下载（需下载时）→ 确定。
  3. 验证：浏览器打开 http://127.0.0.1 应出现 Everything 网页搜索。
  4. 最佳体验：在本机用浏览器打开本站（或 PWA），避免 HTTPS 拦截 localhost；复杂操作仍可用 Everything 桌面版。
