Everything 搜索

连接 Windows 本机 Everything 的 HTTP 服务，在浏览器里极速搜全盘文件。需先在 Everything 里启用 HTTP Server。不会开？看启用教程

无法从当前页面直连本机

HTTPS 站点访问 http://127.0.0.1 可能被浏览器拦截。可改用下方「在 Everything 网页打开」，或在本机用 file:// / localhost 打开本站。

未连接 Everything

请在本机 Windows 安装 Everything 并启用 HTTP Server，再点「测试连接」。

默认端口 80；若改过端口请写成 http://127.0.0.1:8080。Everything 里设置了 HTTP 用户名/密码时在此填写。

怎么启用 HTTP Server？
  1. 安装 Everything：从 voidtools 官网 下载 Windows 版并安装；首次运行会建立索引。
  2. 启用 HTTP：Everything → 工具 → 选项 → HTTP Server 选项卡 → 勾选 Enable HTTP server → 记下端口（默认 80，冲突时可改为 8080）→ 确定。
  3. 验证：浏览器打开 http://127.0.0.1（或带端口）应能看到 Everything 网页搜索。
  4. 安全：HTTP 可搜并下载本机已索引的全部文件，请勿对公网暴露；建议设用户名密码，或仅在本机使用。
