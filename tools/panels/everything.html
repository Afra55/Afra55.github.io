通过本机桥连接 Windows Everything HTTP 服务（解决 HTTPS 站点无法直连问题）：实时过滤、完整语法、排序分页与下载。启用教程

HTTPS 站点不能直连 Everything，需先启动与 ADB 共用的本机桥（默认 17888），由桥转发到 Everything HTTP。

未连接 Everything

需同时：① 运行本机桥 ② Everything 启用 HTTP Server。再点「测试连接」。

Everything 经统一桥代理；协议 devtools-bridge://。还需本机 Everything 开启 HTTP Server。

本机桥与 ADB / FFmpeg 共用（17888、Token devtools-bridge）。Everything 默认 http://127.0.0.1（端口 80；改过请写 :8080）。

怎么启用 HTTP Server？
  1. 启动本机桥：下载 ADB 完整 ZIP → 运行 start-adb-bridge.cmd，保持窗口打开（与 ADB 同一座桥）。
  2. 安装 Everything：从 voidtools 官网 下载 Windows 版；首次运行建立索引。
  3. 启用 HTTP：Everything → 工具 → 选项 → HTTP Server → 勾选 Enable HTTP server → 允许文件下载（需下载时）→ 确定。
  4. 验证：浏览器打开 http://127.0.0.1 应出现 Everything 网页；回到本站点「测试连接」。
