一键安装或升级本机工具（Node、Git、FFmpeg、ADB、yt-dlp）并同步桥文件。已装则安装时跳过；升级会尝试把已装工具升到最新。图文指南

系统：

一键安装（缺啥装啥）

第一次用：装缺失的 Node / Git / FFmpeg / ADB / yt-dlp，并下载桥到 ~/DevToolsBridges。已存在的包不会重装。

一键升级（系统工具 + 桥）

把已安装的 Node、Git、FFmpeg、ADB、yt-dlp 升到包管理器最新版；未装的会顺手装上；同时刷新全部桥脚本。升级前后版本写入 ~/DevToolsBridges/last-upgrade.log。
