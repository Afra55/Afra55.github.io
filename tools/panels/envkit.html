环境管家

一键安装或升级本机工具（Node、Git、FFmpeg、ADB、yt-dlp），并同步统一桥文件。一座桥（17888）覆盖 ADB / FFmpeg / yt-dlp / Git。图文指南

系统：

一键安装（缺啥装啥）

第一次用：装缺失的 Node / Git / FFmpeg / ADB / yt-dlp，并下载桥到 ~/DevToolsBridges。已存在的包不会重装。

一键升级（系统工具 + 桥）

把已安装的 Node、Git、FFmpeg、ADB、yt-dlp 升到包管理器最新版；未装的会顺手装上；同时刷新统一桥所需文件（含嵌套的 ffmpeg-bridge / git-bridge 模块）。升级日志：~/DevToolsBridges/last-upgrade.log。
