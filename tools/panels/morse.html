摩斯密码新手教程：从零学会「看」电码

1. 它是什么？

摩尔斯电码（Morse Code）用两种基本信号表示字符：短信号「点」（dit，写作 · 或 .）和长信号「划」（dah，写作 − 或 -）。通过电报、灯光闪烁、声音嘀嗒均可传递；本工具只做文字形式互转。

2. 先记住三条 spacing 规则（读懂的关键）

  1. 同一个字母内：点划紧挨着写，中间不加空格。例如字母 A = ·−（一点一划）。
  2. 字母与字母之间：空一格。例如 SOS 三字分别为 ···、---、···，合写为 ··· --- ···。
  3. 单词与单词之间：用 / （斜杠两侧可有空格）或至少两个空格。例如 HI BOB = ···· ·· / −··· --- −··。

听音时的时长比例（了解即可）：划 = 3 个点长；字母间隔 ≈ 3 点；单词间隔 ≈ 7 点。看文字版时，用空格和 / 对应即可。

3. 最快上手：5 个超高频字母

英语电报里几乎一半的字母是下面五个，先背它们：

字母电码口诀
E·最简单，一个点
T−最简单，一个划
A·−「啊」短长
O---三划，像说「哦——」
I··两短点

试着在本页上方解码框输入 · / −（勾选「显示为 · / −」），应得到 E T。

7. 怎么「读」一行电码？四步练习

  1. 先找 /，把句子切成单词。
  2. 在每个单词里按空格切成一组点划，每一组对应一个字母。
  3. 对照上表，把每组翻成字母。
  4. 连起来读单词；整句连读即得明文。

练习 1：··· --- ··· → 三组分别是 S、O、S → SOS（国际求救）。

练习 2：.... .. / --. --- → HI / GO → HI GO。

练习 3：-- --- .-. ... . → MORSE（可粘贴到解码框验证）。

8. 本工具约定

  • 编码时字母一律转大写；中文等非拉丁字符不支持，请先用拼音或英文。
  • 输入电码时可写 . 或 ·，可写 - 或 −。
  • 单词分隔推荐 / ；连续两个以上空格也会被当作单词分隔。
