安装本机工具（小白指南）

本站大部分功能在浏览器里就能用。电脑依赖与桥可用 环境管家 一键安装/升级；或按下面图文一步步来。ADB / FFmpeg / yt-dlp / Git 共用一座桥（17888），启动一次即可。全盘搜索请用 外链 · Everything。

你需要装什么？

手机：不用装这些，直接用网页里的音频处理 / 视频修剪即可。电脑：批量任务优先装本机桥；没装或连不上时，网页 FFmpeg 仍可当保底。

要用的网页功能 本机要装
时间戳、JSON、备忘录、GIF、音频修剪等 不用装，打开网页即可
ADB 工具（管安卓手机） Node.js + ADB
FFmpeg 本机桥（批量抽音频等） Node.js + FFmpeg
yt-dlp 本机桥（下载视频 / 播放列表） Node.js + yt-dlp（合并建议 + FFmpeg）
Git 可视化（本地仓库 / 分支图） Node.js + git
两个都要用 Node.js + ADB + FFmpeg（装一次即可）
ADB + FFmpeg + yt-dlp 都要用 Node.js + ADB + FFmpeg + yt-dlp（装一次即可）

嫌步骤多：直接去 环境管家 下载一键脚本。图文顺序：① Node.js → ② FFmpeg / ADB / git（按需）→ ③ 下载桥 ZIP 或跑管家同步 → ④ 点「连接本机桥」。

选择你的系统：

1. 安装 Node.js（本机桥需要）

Node.js 用来在本机运行我们提供的「桥」小服务。装 LTS（长期支持版）即可，不必选最新实验版。

打开 Node.js 官网下载 中文下载页

  1. 打开官网，下载 macOS 安装包（.pkg），双击一路「继续」安装。
  2. （可选，更方便）若已装 Homebrew，也可在「终端」执行：brew install node
  3. 打开「终端」，输入下面两行，回车，应能看到版本号： 
    node -v
npm -v
  1. 打开官网，下载 Windows 安装包（.msi），双击安装。勾选「自动加入 PATH」（默认一般已勾选）。
  2. 关闭并重新打开「命令提示符」或 PowerShell（很重要，否则可能仍提示找不到 node）。
  3. 输入下面两行，回车，应能看到版本号： 
    node -v
npm -v
  1. 优先用官网安装包 / 发行版包，或参考官网 Linux 说明。
  2. Ubuntu / Debian 示例： 
    sudo apt update
sudo apt install -y nodejs npm
node -v
  3. 若版本过旧，建议用 官网 或 nvm 安装较新的 LTS。

看到类似 v20.x.x 就说明 Node 装好了。

2. 安装 FFmpeg（FFmpeg 本机桥需要）

FFmpeg 负责真正的音视频处理。装好后，终端里能跑 ffmpeg -version 即可。

FFmpeg 官网下载页 Windows 常用构建（gyan.dev） Homebrew（macOS）

  1. 推荐用 Homebrew（若还没有：打开 brew.sh，按首页命令安装）。
  2. 终端执行： 
    brew install ffmpeg
ffmpeg -version
ffprobe -version
  1. 打开 gyan.dev/ffmpeg/builds，下载 ffmpeg-release-essentials.zip（或官网推荐的 Windows 构建）。
  2. 解压到固定位置，例如 C:\ffmpeg。确认里面有 bin\ffmpeg.exe。
  3. 把 C:\ffmpeg\bin 加到系统环境变量 PATH：
    • 设置 → 系统 → 关于 → 高级系统设置 → 环境变量
    • 在「用户变量」或「系统变量」里找到 Path → 编辑 → 新建 → 粘贴该 bin 路径 → 确定
  4. 重新打开命令行窗口，验证： 
    ffmpeg -version
ffprobe -version
  1. Ubuntu / Debian： 
    sudo apt update
sudo apt install -y ffmpeg
ffmpeg -version
  2. Fedora：sudo dnf install ffmpeg；Arch：sudo pacman -S ffmpeg。

2b. 安装 yt-dlp（视频下载本机桥需要）

网页 yt-dlp 本机桥 通过本机桥调用命令行工具。装好后终端能跑 yt-dlp --version。合并音视频仍需要上面的 FFmpeg。页面内也有详细教程。

yt-dlp GitHub 官方安装说明 打开 yt-dlp 工具页

  1. 推荐 Homebrew：brew install yt-dlp
  2. 验证： 
    yt-dlp --version
  3. 升级：brew upgrade yt-dlp，或在工具页连桥后点「更新 yt-dlp」。
  1. 推荐 winget： 
    winget install yt-dlp
yt-dlp --version
  2. 或 pipx：pipx install yt-dlp；或从 Releases 下载 yt-dlp.exe 加入 PATH。
  3. 改 PATH 后必须重新打开命令行再验证。
  1. 推荐 pipx： 
    pipx install yt-dlp
yt-dlp --version
  2. Arch：pacman -S yt-dlp；其它发行版见官方 Wiki 或 pip 安装。
  3. 找不到命令时可设环境变量 YTDLP_PATH 指向可执行文件，然后重启桥。

提示找不到 yt-dlp：先在本机终端自测，再重启桥。会员内容可在工具页选「cookies 浏览器」。

3. 安装 ADB（ADB 工具需要）

ADB 用来连接安卓手机。只需「Platform-Tools」这一小包，不必装整个 Android Studio（当然装了 Studio 也自带 adb）。

官方说明与下载页 Windows 直链 ZIP macOS 直链 ZIP Linux 直链 ZIP 国内镜像说明页

  1. 下载 macOS ZIP 并解压，得到 platform-tools 文件夹（内含 adb）。
  2. 可选：移到 ~/platform-tools，并写入 PATH（把下面加到 ~/.zshrc）： 
    export PATH="$HOME/platform-tools:$PATH"
    然后执行 source ~/.zshrc。
  3. 或用 Homebrew：brew install android-platform-tools
  4. 验证： 
    adb version
adb devices
  5. 手机：打开「开发者选项」→ 开启「USB 调试」→ 用数据线连接电脑 → 手机上点「允许」。此时 adb devices 应出现设备序列号。
  1. 下载 Windows ZIP，解压到例如 C:\platform-tools。
  2. 把该文件夹路径加入 PATH（同 FFmpeg 的环境变量步骤）。
  3. 重新打开命令行，验证： 
    adb version
adb devices
  4. 手机开启 USB 调试并授权；若驱动异常，可装厂商驱动或 Android Studio 自带的 Google USB Driver。
  1. 下载 Linux ZIP 并解压，或发行版包：sudo apt install adb（名称因发行版而异）。
  2. 将 platform-tools 加入 PATH 后验证 adb version。
  3. 部分发行版需配置 udev 规则才能稳定识别设备；若 adb devices 显示 unauthorized / no permissions，请搜索「发行版名 + adb udev」。

4. 下载并启动「本机桥」

桥是我们网站提供的小程序：网页通过它调用你电脑上的 adb / ffmpeg / yt-dlp / git。文件不会上传到互联网。

  1. 打开对应页面： 打开 ADB 工具 打开 FFmpeg 本机桥 打开 yt-dlp 本机桥 打开 Git 可视化
  2. 点击「下载完整包」（统一桥：含 ADB / FFmpeg / yt-dlp / Git）。请解压后保留子目录结构。
  3. 建议解压到固定目录，并在 ADB 页「桥解压目录」里填入路径（输入即自动记住）。需要时点「打开目录」在本机查看。首次请手动运行启动脚本（会注册 devtools-bridge://）；之后进入相关工具页可自动尝试启动。
  4. 运行启动脚本：
    • macOS：双击或 chmod +x … && ./…
    • Windows：优先双击 .cmd，保持黑色窗口不要关
    • Linux：给脚本执行权限后运行
  5. 回到网页点「连接本机桥」。默认地址：
    • 统一本机桥：http://127.0.0.1:17888，Token devtools-bridge（ADB + 镜像 + FFmpeg + yt-dlp）
    • FFmpeg 接口前缀：/ff（例如 /ff/ops）
    • yt-dlp 接口前缀：/ytdlp（例如 /ytdlp/health）
    • 统一桥：http://127.0.0.1:17888，Token devtools-bridge（含 ADB / FFmpeg / yt-dlp / Git）
    • Git API：统一桥上的 /git/*

窗口一闪就关：多半是没装 Node / 缺 server.js / 端口占用。日志在启动脚本同目录的 last-start.log；镜像用的 vendor/scrcpy-server-v3.1 也会下载到该目录。

5. 常见问题

提示找不到 node / ffmpeg / adb / yt-dlp
确认已安装；Windows 改完 PATH 后必须新开终端；用上面的 -v / -version 命令自测；yt-dlp 装好后需重启桥。
桥连不上
确认启动窗口还在跑；地址端口别填错；浏览器要用 https 本站或本机预览，不要用 file:// 直接打开 HTML。
手机 adb devices 是空的
检查线材、USB 调试、手机上的授权弹窗；换口 / 换线；部分机型要开「仅充电」以外的文件传输模式。
手机上怎么用 FFmpeg？
手机装不了本机桥。请用 音频处理 / 视频修剪（网页内 FFmpeg）。电脑批量再用本机桥。
只想批量抽音频，要不要装 ADB？
不用。装 Node.js + FFmpeg，用 FFmpeg 本机桥 即可。
偶尔处理一两个视频，要不要装本机桥？
不必。用媒体里的「音频处理 / 视频修剪」等浏览器内工具就够（也是保底方案）；批量下载或整列表再用 yt-dlp 本机桥。
下载视频只要 yt-dlp，要不要装 ADB？
不用。装 Node.js + yt-dlp（合并建议 + FFmpeg），用 yt-dlp 本机桥 即可；与 ADB 共用同一座桥。
只想看本地 Git 分支图？
装 Node.js + git，任意桥页下载统一完整包（已含 Git）启动一次即可。
